# v0.2 Protocol Implementation

**Date:** 4 October 2026

This change implements the methodological blockers identified in the v0.2 repository audit before any empirical signal search is started.

## Data freeze and adjustment

The baseline configuration has an explicit end date of 3 October 2026 (exclusive in the Yahoo adapter). Rolling data are rejected by the development script.

The Yahoo adapter now requests adjusted OHLC prices with `auto_adjust=True`. Provider-exported data are still supported, but the research protocol requires a documented and consistent adjusted-price convention.

## Immutable hold-out calendar

`scripts/freeze_holdout.py` constructs the final 252 eligible decision dates from the market-data/target calendar, before feature engineering, and writes them to `configs/holdout_dates.csv`.

`scripts/run_baseline.py` refuses to run without that manifest. It also checks that the manifest is the final eligible block of the frozen data window.

The modelling frame no longer determines the hold-out boundary, so adding a feature with different missingness cannot move the hold-out.

## Pre-hold-out embargo

Six decision dates ((h+1) for the five-session target) immediately before the hold-out are excluded from development.

This keeps development labels and the final development portfolio sleeves from using the hold-out outcome path.

## Horizon-consistent portfolio

Each decision date produces a cohort portfolio from the five-session forecast. The live portfolio is the equal-capital sum of five staggered sleeves, with each cohort contributing (1/5) of its target weights for five consecutive one-session open-to-open return periods.

The final cohort is allowed to run off over the embargo calendar. Transaction costs are then charged on changes in the composite live portfolio:

[
C_t = c\sum_i |w_{i,t}-w_{i,t-1}|.
]

This replaces the v0.1 mismatch between a five-session forecast and a one-session portfolio interpretation.

## Tests added

The CI suite now checks:

- Yahoo adjusted-price request;
- hold-out manifest round trip;
- hold-out invariance to feature missingness;
- six-session pre-hold-out embargo;
- staggered sleeve mechanics and runoff;
- horizon-consistent realised-return alignment.

No hold-out outcomes are evaluated by these changes.
